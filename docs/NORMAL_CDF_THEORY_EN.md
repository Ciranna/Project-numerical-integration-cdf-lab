# Homework 5 — Exercise 2: Numerical Computation of the Normal CDF

## Theory
The standard normal density is phi(x)=exp(-x²/2)/sqrt(2π). Its CDF is Phi(x)=integral from -infinity to x of phi(t)dt. Symmetry gives Phi(x)=1/2+integral from 0 to x phi(t)dt, including negative x using oriented integration. Thus finite-interval quadrature needs no arbitrary tail cutoff.

The Gaussian density has no *elementary* antiderivative. Liouville's theorem on elementary integration characterizes the form an elementary antiderivative would have; the Gaussian exponential does not admit one. This does not preclude an exact representation using a special function: Phi(x)=(1+erf(x/sqrt(2)))/2.

## Methods
- Composite trapezoidal quadrature on [0,abs(x)], with symmetry for negative x. Error order O(n^-2) for fixed x and smooth density.
- Composite Simpson quadrature, requiring an even n. Error order O(n^-4) for fixed x and smooth density.
- Truncated Maclaurin series of erf: (2/sqrt(pi)) sum from k=0 to infinity of (-1)^k z^(2k+1)/(k!(2k+1)). This converges for every fixed z, but direct floating-point evaluation can lose accuracy for large |z| due to cancellation.
- Abramowitz & Stegun 7.1.26 approximation for erf, with typical maximum absolute error about 1.5e-7; this is an approximation, not an exact implementation of erf.

## Reference and limitations
The application includes fixed high-precision normal-CDF reference values at selected points (not generated by the methods under test). For arbitrary x, the UI deliberately reports no tabulated reference rather than inventing an error. The plot spans [-4.5,4.5] while numerical methods can accept a wider x range.
